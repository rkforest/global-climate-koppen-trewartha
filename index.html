Introduction

This project analyzes changes in global climate classification across three climate intervals, beginning with the 1961–1990 WMO Climatological Reference Period and extending through the 2021–2025 Recent Climate Interval, using ERA5 temperature and precipitation data from the Copernicus Climate Data Store.

The analysis applies the Köppen–Trewartha climate classification system consistently to each interval, compares the resulting climate classifications, quantifies transitions among climate groups and types, and maps where those transitions occur.

Climate Periods

The project uses three non-overlapping analysis periods and one consistent terminology throughout the workflow:

  • WMO Climatological Reference Period (1961–1990) — the 1961–1990 period retained by WMO as a standard reference period for long-term climate-change assessment.
  • WMO Climatological Standard Normals (1991–2020) — the current WMO 30-year climatological standard normal.
  • Recent Climate Interval (2021–2025) — a project-defined recent five-year interval used to identify emerging climate signals. It is not a WMO climatological normal.

For compact tables or figures, the project uses the abbreviations REF, CSN, and RCI. These labels are intended to be used consistently in this project and in the companion Global Temperature Change Analysis project.

Köppen–Trewartha Climate Classification

The Köppen–Trewartha climate classification used in this project contains six broad climate groups and thirteen climate types:

  • Group A — Tropical
    • Ar — Tropical Rainforest
    • Aw — Tropical Savanna
  • Group B — Dry
    • BW — Desert (Arid)
    • BS — Steppe (Semiarid)
  • Group C — Subtropical
    • Cs — Mediterranean (dry summer)
    • Cw — Subtropical (dry winter)
    • Cf — Subtropical (no dry season)
  • Group D — Temperate
    • Do — Temperate (Oceanic)
    • Dc — Temperate (Continental)
  • Group E — Boreal
    • Eo — Boreal (Oceanic)
    • Ec — Boreal (Continental)
  • Group F — Polar
    • Ft — Tundra
    • Fi — Ice Cap

Workflow

Workflow

The project uses monthly ERA5 temperature and precipitation climatologies prepared by the companion ERA5-DATA project. That project handles ERA5 acquisition and transformation, producing reusable datasets for the REF, CSN, and RCI climate intervals.

The climate-classification analysis is organized into four sequential stages:

  1. Determinant Calculation
    Read the transformed ERA5 climatologies from the shared ERA5-DATA project and calculate the temperature, precipitation, and aridity determinants required by the Köppen–Trewartha classification system.

  2. Climate Classification
    Apply the same Köppen–Trewartha classification rules to each grid cell for the REF, CSN, and RCI climate intervals; create the classification reference tables and coastline layer; and summarize the resulting climate groups and types.

  3. Transition Analysis
    Quantify climate-group and climate-type transitions for REF → CSN, CSN → RCI, and REF → RCI; examine transition matrices; and calculate gains, losses, and net classification changes.

  4. Transition Mapping
    Map the geographic distribution of climate-classification changes, including broad spatial patterns, expansion of dry and desert classifications, retreat of polar classifications, and the long-term REF → RCI transition pattern.

The ERA5-DATA and Global Climate Classification — Köppen–Trewartha projects are maintained as sibling directories under ~/Projects/. Shared climate datasets remain in ERA5-DATA, while classification determinants, classifications, transition datasets, and mapping outputs belong to this analysis project.

Data

This analysis uses ERA5 reanalysis data produced by the European Centre for Medium-Range Weather Forecasts (ECMWF) and distributed through the Copernicus Climate Data Store.

The companion ERA5-DATA project acquires and transforms the source data into reusable monthly climatologies for the three analysis intervals (REF, CSN, and RCI).

The shared datasets contain:

  • Monthly 2 m air temperature
  • Monthly total precipitation

These transformed datasets are read from the sibling project at ../era5-data/data/transformed/.

The climate-classification project maintains its own derived analytical datasets and static reference data, including:

  • Köppen–Trewartha climate-group definitions and colors
  • Köppen–Trewartha climate-type definitions and colors
  • Natural Earth global coastline data

The ERA5 land-sea mask is an additional source dataset used in the broader data-preparation workflow.
